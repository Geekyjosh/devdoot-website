# Devdoot

### Healthcare, Emergency Response & Volunteer Platform

**Live Website:** [https://devdoot.org/](https://devdoot.org/)

## Overview

Devdoot is a full-stack digital platform focused on healthcare support, emergency response, volunteer coordination and educational resources.

I worked on the development of the platform across the frontend and backend, implementing responsive interfaces, application functionality, API integrations and data-driven features.

## My Role

**Full-Stack Web Developer**

I was responsible for frontend development, backend implementation, API integration, database functionality and the overall web application experience.

## Tech Stack

- React
- Next.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- PostgreSQL
- Cloud API Gateways
- AWS CloudFront

## Frontend Development

- Built user interfaces using React and Next.js
- Implemented responsive layouts with Tailwind CSS
- Developed reusable UI components and application sections
- Utilized Next.js Server-Side Rendering for dynamic application experiences
- Implemented static generation where appropriate for optimized page delivery
- Focused on responsive and accessible user experiences across devices

## Backend & API

- Developed backend functionality using Node.js and Express.js
- Implemented API endpoints and server-side application logic
- Integrated cloud API gateways for platform functionality
- Supported healthcare matching features and educational modules
- Connected frontend application workflows with backend services

## Database

- Used MongoDB for user profiles and related application data
- Used PostgreSQL for structured data and real-time session requirements
- Implemented data flows between application services and database systems

## Infrastructure

- Utilized a JAMstack-oriented architecture for application delivery
- Deployed and delivered application resources through AWS CloudFront
- Supported production infrastructure and content delivery
- Focused on reliable and responsive application performance
